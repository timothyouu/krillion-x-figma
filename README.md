# Krillion x Figma

A Figma-themed trivia game built by the Figma Campus Leader Social Team as the icebreaker for the Midyear All Hands (Dec 8, 2026). Inspired by Krillion, it runs 5 rounds of Figma questions with a live leaderboard so Campus Leaders can play together during the call.

## How it plays
- Players join from their own device
- 5 themed rounds of Figma trivia
- Scores update live on a shared leaderboard
- Built for desktop and tablet first

## Stack
- Frontend: built by Timothy
- Backend: Supabase for questions, players and the leaderboard, built by Chris
- Hosting: Vercel

## Run it locally
1. Clone the repo
2. Install dependencies: `npm install`
3. Add a `.env.local` with your Supabase URL and anon key
4. Start the dev server: `npm run dev`
